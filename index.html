How it works: one screen, from brief to shipped

  1. The problem first

    01 Brief

    What it's for, and who uses it.

    Before any tool opens, I write the problem down in plain words.

  2. Layer 01 · pencil on paper

    02 Sketch

    Rough lines, cheap to change.

    Every screen is drawn by hand first, so I can try many layouts before keeping one.

  3. Layer 02 · structure, no colour

    03 Wireframe

    Boxes, hierarchy and flow.

    In Figma, grey on purpose, so the layout is judged on its own.

  4. Layer 03 · type, colour, states

    04 Design

    Decided before the code.

    Type, colour and every state. The finished design is the spec I build against.
