# Nicho.dev

Portfolio of Nicho Lescano, UI/UX designer and developer.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` through any static server, for example:

```bash
npx serve .
```

- `index.html`: the landing (a layered stack per project) and the scrolling page
- `desk.html`: a 3D room built with Three.js, with a working laptop desktop inside
- `projects.html`: case studies
